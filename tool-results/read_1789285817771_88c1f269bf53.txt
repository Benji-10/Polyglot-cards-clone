    13→    13→- Next.js 16 App Router, TypeScript, Tailwind CSS 4, shadcn/ui (New York).

    31→    31→  `<main className="flex-1 overflow-y-auto scrollbar-thin">`. Use

    47→    47→  `EXTRA_TYPES`, `DEFAULT_BLUEPRINT` (5 fields), `QUICK_ADD_FIELDS`,
    48→    48→  `LEARNING_STEPS` = [1,10] min, `MATURE_THRESHOLD` = 21 days,

    52→    52→  `predictInterval(prev, rating)` → string like "5d"/"1m"/"10m",
    53→    53→  `formatIntervalDays(days)`, `isMature(intervalDays)`, `isDue(dueAt, now?)`.
    54→    54→  The `SrsStateData` interface = the card's SRS fields.
    55→    55→- `auth.ts` — `AuthUser`, `isNetlifyIdentityConfigured()`, client helpers
    56→    56→  `getStoredAuthUser/storeAuthUser/getOrCreateLocalGuest`, GoTrue calls
    57→    57→  `netlifySignup/netlifyLogin/netlifyRecover`, server `resolveServerUser`.
    58→    58→- `api-client.ts` — `api.get/post/put/patch/del(url, body?)` auto-attaches
    59→    59→  auth headers. `ApiError` with `.status`.
    60→    60→- `ruby.ts` — `parseFurigana(text, furigana)`, `splitExamples(raw)`,
    61→    61→  `parseCloze(sentence)` → `{display, answer, hasCloze, before, after}`,
    62→    62→  `fieldValueToString`, `fieldValueToAnnotated`, `phoneticsFor(ann, phonetics)`.
    63→    63→- `similarity.ts` — `gradeAnswer(expected, given, strictMode, strictAccents)`

    65→    65→  `normalize`, `stripAccents`, `containsCJK`.
    66→    66→- `tts.ts` — Web Speech API wrapper: `speak(text, {lang, rate})`,
    67→    67→  `stopSpeaking()`, `isTtsSupported()`, `primeVoices()`, `getVoices()`.
    68→    68→- `mappers.ts` — server-side Prisma→type mappers (not needed in UI).
    69→    69→- `seed.ts` — sample decks (Japanese furigana, Mandarin pinyin, French IPA,
